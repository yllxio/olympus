# Материалы: что куда добавлять

Это JSON — обычные текстовые файлы. Angular для заполнения не требуется: приложение использует React и официальный MAX UI.

| Папка | Содержимое | Связь |
| --- | --- | --- |
| content/topics | Темы | Постоянный id темы |
| content/lessons | Теоретические уроки | topicId = id темы |
| content/tasks | Задания | topicId = id темы |
| content/mock-tests | Пробники | taskIds = список id заданий |
| content/olympiads | Календарь | Самостоятельные записи |
| public/materials | Картинки и PDF | /materials/имя-файла |

В каждой папке есть initial.json с полными подготовленными материалами и папка imports для ваших файлов. Разрешён один объект или массив объектов. Названия файлов любые на латинице. Комментарии и лишняя запятая в конце JSON не разрешены.

## Правила связей

- ID уникален для всего проекта. Для обновления сохраняйте ID, для новой записи придумайте новый
- grade — число 4, 5 или 6; subject — math или info
- У уроков и задач topicId должен точно совпадать с существующей темой
- order задаёт порядок внутри темы, от 1
- Для новой темы добавьте пять уроков и пять заданий; админка допускает и больше
- У урока blocks — блоки внутри одного урока, а не пять отдельных уроков
- Пробник относится к одному классу, одному предмету и одной олимпиаде (название в olympiad). Поле olympiad — текст для фильтра, не ID календарной карточки
- Пробник ссылается на существующие задания того же класса/предмета
- Для математики type=number с answer либо proof с solution. Для информатики type=code, tests с входом/выходом; отдельные задания под каждый язык не нужны
- points — баллы за задачу, по умолчанию 1. minutes — длительность пробника
- Олимпиада: grades — массив чисел, online/offline, region для очного формата, deadline и date в формате ГГГГ-ММ-ДД
- URL регистрации — официальный HTTPS-адрес регистрации, предоставленный вами
- Блоки: text, example, list, table, formula, code, image, video, link. value — строка; caption — необязательная подпись
- Картинку или PDF можно положить в public/materials и использовать /materials/file.pdf. Файлы из админки находятся в другом, серверном хранилище

## Примеры действующих форматов

Ниже связанные примеры из проекта. Перед добавлением НОВЫХ записей замените ID и все ссылки на них согласованно. Если используете тот же ID, обновится существующий материал.

### Тема

```json
{
  "id": "math-4-01",
  "title": "Чётность и нечётность",
  "grade": 4,
  "subject": "math",
  "order": 1,
  "description": "Теория и пять заданий для самостоятельной подготовки",
  "demo": false
}
```

### Урок

```json
{
  "id": "math-4-01-lesson-1",
  "title": "Главная идея",
  "topicId": "math-4-01",
  "order": 1,
  "blocks": [
    {
      "type": "text",
```

## Проверка перед публикацией

В папке проекта выполните `node scripts/compile-content.mjs`. Проверяются JSON, ID, ссылки на темы/задачи, класс и предмет, даты и поля ответов. Ошибка останавливает сборку. Саму методическую правильность текстов и решений нужно проверить вручную.

`lib/seed.json` генерируется автоматически: редактируйте content, а не seed.json.
